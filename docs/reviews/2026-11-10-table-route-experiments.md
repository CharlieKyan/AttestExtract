## 2. 核心逻辑与兼容性

- `build_table_input` 复用现有精确Unicode位置与MinerU结构，不接收人工列号或布局提示；模型只见选中整表和已定位标题/表题/脚注，不见完整论文的其他内容或参考答案。
- `build_route_request` 的A阶段返回字段来源；B1返回自然语言及独立溯源记录；B2只接收任务和句子，不接收原格索引或B1隐藏绑定。该入口使用独立的`table-route-v1`实验结构，不调用普通flat-v1结果解析器。
- `evaluate_route` 核验原格和格内精确范围，支持重复文字的显式offset；值和单位从指定原文回读。多测量记录逐一检查共享身份、条件与单位，不以一个合法anchor为整条记录背书。
- 合并身份允许共用；合并测量必须有group/each范围依据。组量不能赋予只覆盖部分范围的成员；显式否定分配语句被阻止。范围与几何检查不证明语义必然正确。
- `reconcile_results` 自动替换唯一对应的未检查旧记录，保留历史并单列新增事实；已有检查结果冲突则保留、报出冲突，不冒充专家审核或改写正式归档。
- `run_bundle` 先保存请求和独占预留再调用；中断后未知试次不重发；B1格式/传输失败跳过B2，格式有效的内容错误继续进入B2以观察传播。不转移失败额度。
- `fork-replay` 新建只能离线运行的目录，旧日志不变。改B1不会真实重推B2；未覆盖的B2仍是先前回答，文档明确其含义。

## 3. 独立审阅发现与修复

| 实际触发条件 | 修复及验证 |
| --- | --- |
| 同条记录将反应前压力与反应后时间拼接，条件只需匹配一个anchor | 为每个measurement单独核对身份、条件及单位；独立跨条件反例阻止 |
| 横向合并总量绑定到一个成员列标题 | 按绑定方向要求身份范围完整覆盖合并测量；横向分组反例阻止 |
| 从100中截取10，或从MPa中截取Pa | 新增数值/单位词边界检查，保留完整原值纠错能力 |
| B1转写错误只挂句号ID，所属记录仍显示source_checked | 同时记录真正record_id、statement_id、field及源引用；该记录进入未解决，B2仍可独立回读修复 |
| 报告入口导入不存在模块，或修改response后直接生成报告 | 修复包内导入；生成报告前检查全部试次证据hash |
| 值正确但引用另一个同值原格 | 值评分与冻结的逐字段原格评分分开；来源未标注或B2尚未接回原文时明确未评估 |

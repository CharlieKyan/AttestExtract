## 2. 核心逻辑变化

| 函数或规则 | 修改前 | 修改后与影响 |
| --- | --- | --- |
| `apply_decision()` | 歧义可使整组提案无法应用；部分提案错误首先抛出，后续问题不一定可见。 | 生产调用提供 `review_items`，先确认全局完整性，再分别暂存对象、关系及归属的校验结果。可检查的局部问题汇总到原提案；有效结果独立保留。未传 `review_items` 的直接调用保持严格报错行为，复用同一套验证逻辑。 |
| 归属契约 | 模型可能把“值有证据”误作“归属有证据”，或认为没有既存 ID 就不能声明对象。 | 明确 `status` 只判断直接归属。`supported` 必须引用合法对象且提供证据；`unknown` 必须为空主体，`target_match` 独立判断。允许声明原文支持的新对象及局部 ID；稳定 ID 仍由程序生成。 |
| 提案依赖 | 歧义影响整组，即使其他观测不依赖错误对象。 | 错误对象只阻断明确引用该局部对象 ID 的关系及绑定。错误绑定只隔离自身；错误关系不自动阻断独立有证据的绑定。当前协议没有绑定到关系 ID 的引用，不推测隐含的语义依赖。 |
| 证据提交 | 整组应用或隔离。 | 各提案的证据和展示上下文独立暂存；被拒绝提案的证据不进入已应用图。全局错误在提交任何本组变更前停止；有效对象 ID 的生成方式不变。 |
| `_advance()` / `build_verification()` | 歧义异常触发整组待复核。 | 逐项诊断保存为 `proposal_review`；作业为 `review_required`，仍可处理后续独立作业。对象或关系单独被拒绝，即使隔离观测数为零，整次分析仍为 `partial`。 |
| `_review_signature()` / 恢复 | 校验整组歧义位置。 | 重放已保存回答，核对诊断摘要、逐提案问题、匹配位置和保留／隔离集合。恢复不重新发送已保存的失败提案，也不重新发放预算；诊断或缓存损坏在新请求前报错。 |
| `is_review_only_partial()` / `_validate_review_materials()` | 识别分析 0.3 的整组待复核。 | 支持 0.4，核对全部目标不重复、不遗漏，保留与隔离集合互斥且完整；拒绝把失败、待处理或预算耗尽伪装成仅待复核。 |
| 分析导出与报告 | 一组的全部观测作为隔离集合。 | `target_observation_ids` 是本组全部目标，`observation_ids` 仅为隔离观测，`applied_observation_ids` 为其余已处理观测。合法 `unknown` 属于已处理，不等于已确认归属；不能据此进入目标对象单元格。 |

每条被隔离的绑定保留原观测值、单位、条件和原始提案；应用状态为 `review_required`，不带主体或绑定证据，另有明确的程序拒绝原因。程序不会将模型的错误 `supported` 悄悄改写为模型作出的 `unknown`。

分析产品及分析检查点更新为 **0.4**，兼容修订号为 **`bounded-source-verification-v5`**。旧 0.1／0.2／0.3 结果仍可读取和导出，0.3 仍按历史整组隔离含义展示；旧分析检查点不能在 v5 下继续恢复。抽取结果 schema、抽取兼容修订号及抽取缓存复用规则未改变，可保留旧运行并在新分析分支复用经校验的抽取结果。

## 3. 潜在问题

独立审阅发现过一个导出防御缺口：单个待复核组内部集合有效，不足以证明所有作业之间没有重复目标或遗漏目标。现已在 0.4 导出校验中检查全局作业目标集合，增加重复与遗漏两类损坏用例。该问题已修复，未留下已确认的阻断项。

已检查证据不泄漏、原回答不覆盖、合法未知归属保留、坏对象显式依赖传播、关系单独隔离、恢复一致性、旧结果读取及公开入口的退出码边界。以下限制仍然成立：

- 只有**整体可解析且满足 `Step` 类型结构**的 `decide` 回答才能逐提案处理。非法 JSON、错误字段类型、缺失结构，或重复／陌生／遗漏的目标引用仍整体失败；HTTP 完整返回不改变这一规则。
- 对象 ID 声明冲突、来源或可见位置索引损坏不能安全分区，仍在应用本组变化前停止。
- 依赖传播仅跟随显式对象引用。某个保留的绑定在科学含义上可能依赖被拒绝的关系，当前协议无法识别这种隐式依赖；因此保留结果仍是模型提案，不能自动视为可信分析表。
- 校验收集的是可独立检查的问题，不承诺发现全部事实错误。引文可定位、主体引用合法或类型正确，均不能证明科研归属正确。
- 展示仅通过检查的对象表可能偏向容易的样本。报告须同时查看全部观测、合法未知归属、隔离项和待处理数量，不以对象表行数替代抽取覆盖或质量验收。
- 本轮不新增自动纠错、额外模型重试、ID 猜测、Jev 接入或人工结论写回；隔离项需要后续复核，普通恢复不会自动修好它们。
